二、選擇繳交案例（活動 08）

我選擇的活動： 活動 08

原本有什麼問題，或我想改善什麼：
原本的網頁固定寬度 960px，在手機或窄視窗觀看時會產生橫向捲軸，輸入框也固定 420px 容易超出畫面。

我親手修改／告訴 Agent 的具體要求：

請幫我將 08-css-rwd.html 的版型修改為響應式網頁設計（RWD）。具體要求如下：

  1. 將原本固定寬度 960px 的 .page 主容器，改為寬度 100% 且最大寬度 960px（width: 100%; max-width: 960px;）。
  2. 將原本固定寬度 420px 的 input 輸入框，改為寬度 100% 且最大寬度 420px（width: 100%; max-width: 420px;）。
  3. 加入 Media Query 判斷，當螢幕寬度小於或等於 600px 時（@media (max-width: 600px)），將 .cards 的三欄卡片版型切換為 1fr（單欄垂直排列）。
  4. 修改後必須確保內容完整保留，且在手機視窗下不會出現橫向捲軸或內容溢出。

完成了哪些修改：

  1. 將 .page 的 width: 960px 改為 width: 100%; max-width: 960px;
  2. 將 input 寬度改為 width: 100%; max-width: 420px;
  3. 新增 @media (max-width: 600px) 規則，將 .cards 的 grid-template-columns 改為 1fr (單欄)。

我如何檢查，實際看到什麼結果：
將瀏覽器視窗拉窄測試，當寬度小於 600px 時，三張卡片順利垂直排列成單欄，頁面與輸入框皆完美適應螢幕寬度，完全沒有出現橫向捲軸。
