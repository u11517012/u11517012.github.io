🍕 Taste the World 期末英打遊戲歷程

數位科技概論專案 — 開發歷程與版本迭代紀錄

Development Versions

Version 1.0

Taste the World — 基礎打字闖關原型

確立「環球美食 × 英文打字」的核心概念，完成最基礎的輸入比對與過關判定機制。

📌 V1.0 核心架構與版本限制

  • 單字與短句練打機制：直接以各國代表性美食單字與長句作為關卡題庫，建立即時字元輸入比對邏輯。
  • 初學者門檻較高：缺乏鍵盤視覺提示與指法分級，對完全沒有盲打基礎的玩家較具挑戰性。
  • 無狀態單機架構：未加入本地端或雲端儲存功能，重新整理網頁後所有通關進度即會重置。
🎮 試玩 V1.0 版本 ↗
Version 2.0

Taste the World 2.0 — 視覺化盲打教學系統

針對初學者痛點全面重構教學曲線，導入虛擬鍵盤手位引導與本機存檔記憶機制。

🚀 V2.0 更新重點與功能改進

  • 虛擬鍵盤與手位指引 (Visual Keyboard)：新增螢幕下方動態鍵盤，即時高亮下一顆應按鍵位與對應手指提示，幫助新手建立肌肉記憶。
  • 漸進式盲打教學曲線：將關卡重組為「基準鍵位 → 上排鍵位 → 下排鍵位 → 綜合單字」的循序漸進練習結構。
  • 本機進度記憶 (LocalStorage)：首次導入瀏覽器本地儲存，自動記錄玩家解鎖的關卡與通關狀態，重開網頁可接續遊玩。
  • 多國地圖與響應式介面：加入世界地圖選關介面與錯字即時反饋特效，提升操作流暢度與視覺體驗。
🚀 試玩 V2.0 版本 ↗
Version 3.0

Taste the World 3.0 — 50 國環球航空遊戲化

全面升級為「環球航空主題」，大幅擴充關卡規模至五大洲 50 國，並建立完整的成就與護照收集系統。

✈️ V3.0 更新重點與系統擴充

  • 五大洲 50 國航線與三階段晉級：擴充至 50 個國家美食關卡，每國皆設計「備料初階、烹飪進階、上菜流暢」三道關卡，結合飛行里程（km）與航速（WPM）數據追蹤。
  • 陪同飛行員系統 (Co-Pilot)：新增 9 位可自由切換的陪同飛行員角色，在練打過程中提供專屬台詞鼓勵與即時指法提示。
  • 突發事件「食材結凍」機制：關卡中隨機生成藍色冰塊字元，需「連按 2 下」敲碎冰塊，成功通關可獲得雙倍里程獎勵。
  • 高難度雙副本挑戰：主線通關後解鎖限時雙倍獎勵的「🔥 美食暴走 Fever」與零失誤挑戰「💣 廚房炸彈菜單」（通關可解鎖護照金框 👑 與暗黑料理吐槽彩蛋）。
  • 通關護照與諧音梗成就：新增 50 國邊檢國旗印章護照與 10 款抽象諧音梗成就徽章，大幅強化長期練打的收集動力。

Version 4.0 (Latest)

Taste the World 4.0 — 雲端帳號同步與飛行員社交版

串接 Google Apps Script (GAS) 雲端資料庫，從單機遊戲進化為支援跨裝置存檔、全服即時排行榜與個人練習手札的完整線上系統。

☁️ V4.0 更新重點與全端功能升級

  • GAS 雲端資料庫與多帳號系統：串接 Google Sheets 後端 API，玩家只需輸入飛行員代號即可將里程、星數、護照印章與成就即時同步至雲端，實現跨電腦、手機無縫接軌。
  • 全體飛行員即時排行榜 (Leaderboard)：新增全服玩家排名系統，即時同步並展示所有飛行員的累積里程、通關國家數、最高航速與副本星數，並標示個人目前名次。
  • 旅行練習筆記本 (Travel Notebook)：新增互動式題庫複習手札，自動彙整各國指法重點與單字，並支援玩家自由撰寫與儲存個人練字心得筆記。
  • 舊版存檔自動遷移救援：內建本機存檔偵測與自動搬移機制，可將早期版本的單機遊玩紀錄無痛轉移至指定雲端帳號下，避免進度遺失。
  • 無縫連貫出餐與快速登入優化：優化通關結算後的 3 秒自動跳轉下一關節奏，並加入記憶上次登入帳號的一鍵快速登機體驗。
