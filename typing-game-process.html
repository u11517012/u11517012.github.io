🍕 Taste the World 期末英打遊戲歷程

數位科技概論專案 — 開發歷程與版本紀錄

Development Versions

Version 1.0

Taste the World

初始原型版本，設計較為硬核，直接以單字、句子與文章進行闖關。

📌 版本特點與限制

  • 直接以長單字與句子作為過關條件，對初學者門檻較高。
  • 無視覺化鍵盤與指引提示，需要盲打基礎。
  • 單一地圖設計，缺乏遊戲進度與通關紀錄儲存。

Version 2.0

Taste the World 2.0

重構教學邏輯與 UI 介面，新增虛擬鍵盤指引提示與進度記憶功能。

🚀 V2.0 主要修改與更新亮點

  • 實時鍵盤指引 (Visual Keyboard Guide)：闖關時新增虛擬鍵盤輔助，動態高亮下一顆應按按鍵與對應手指手位，引導初學者建立盲打肌肉記憶。
  • 進度記憶功能 (Data Saving)：新增本地儲存機制，能自動記錄玩家已解鎖關卡、通關紀錄與個人練習進度，重新開啟網頁即可繼續遊玩。
  • 初學者友善 — 盲打教學體系：改為由淺入深「一排一排鍵盤」逐步練習，待熟悉鍵盤位置後才進入單字闖關。
  • 世界地圖與關卡選擇：新增多國美食關卡地圖，讓玩家自主選擇學習進度。
  • 動態背景與視覺優化：加入動態背景特效與字元高亮提示，大幅降低打字疲勞感。
  • 即時反饋與響應式 UI：優化錯字提示與介面排版，完美適應不同裝置螢幕。
